# ML-проект: предсказание цен на недвижимость

## Задача
Предсказать стоимость квартир на основе 170+ признаков.

## Данные
Данные не включены в репозиторий. Скачать: [ссылка]. Файл `train.csv` должен лежать в папке `data/`.

## Этапы работы
- EDA, очистка, заполнение пропусков
- Кодирование категорий (OHE, target encoding)
- Отбор признаков (корреляция > 0.9, квазиконстантные)
- Удаление выбросов по квантилям
- Обучение Lasso с GridSearchCV и TimeSeriesSplit
- Сегментация по типу недвижимости

## Результаты
- Базовая модель: MSLE ~0.303
- После удаления выбросов: MSLE ~0.17
- Сегментация (2 модели): MSLE 0.08 и 0.18
